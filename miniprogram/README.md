# 微信小程序源码

使用微信开发者工具直接导入当前目录。

- 本地数据键：`fetal-diary-records-v1`、`fetal-diary-settings-v1`
- AppID：当前配置为小程序测试号，可用于开发预览
- 正式发布：将 `project.config.json` 中的测试号 `appid` 替换为已注册小程序的正式 AppID
- 无网络请求、无服务器、无数据库
- 时间线中的每条记录都可以单独修改日期和时间，也可以删除

## 修改记录

进入底部“时间线”，默认查看近 7 天；可以切换“今天”或“全部”。记录较多时默认使用“紧凑”两列视图，也可以切换回“列表”。较早日期默认折叠，点击日期标题即可展开。每条记录都会显示完整日期和时间。点击某条记录右侧的“修改”，在展开的面板中选择日期和时间后点击“保存修改”。首页“最近记录”中的任意一行也可点击进入同一个编辑面板。未来时间不允许保存，修改后统计会同步刷新。

## 本机离线模式

首版不启用手机号认证，入口已隐藏，`config.js` 的 `cloudEnvId` 保持为空。所有记录只保存在当前手机微信中，不需要服务器或数据库；请定期导出 CSV，避免换机或清理微信数据造成记录丢失。
